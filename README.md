# Simple Todo

A clean, minimal to-do list app for Android. Add tasks, mark them done, and stay organized — no clutter, no accounts, no ads.

## Features

- ✅ Add, edit, and delete tasks
- ✅ Mark tasks as complete/incomplete
- 💾 Local storage — your data stays on your device
- 🌙 Light and dark theme support

## Tech Stack

- **Language:** Kotlin
- **Architecture:** MVVM
- **UI:** Jetpack Compose
- **Local Storage:** Room database
- **Async:** Coroutines / Flow
